# Especificações de mudanças

Use [o fluxo do projeto](../docs/spec-driven-development.md) para mudanças
complexas ou ambíguas. Copie os três arquivos de `_template/` para um diretório
`<ano-mes>-<tema>/` e substitua as instruções entre colchetes. Cada diretório
registra uma mudança delimitada; não é um inventário do sistema inteiro.
